# Factory Rush! Ver 1.0 - An old Passion Project
This was an old Passion Project made around 2024 when I was in Secondary 4. As I was very delighted with the outcome of my previous game, I decided to make a second one, learning from the first. It is a time-reaction game built around the premise that you are a factory worker enslaving your life away to an evil-mega-corporation that exploits its workers to minimum wage, tedious job (not really a fantasy if you ask me). 

Given a set of tools, you are to 'fix' the items given to you. Select the correct tool to fix the given item. Using the wrong tool will give you a 'Strike', which if 3 strikes are given out, you will be FIRED (game loss). You are also required to do this as quickly as possible, as your evil-mega-corporation simply cannot afford to waste a millisecond on you deciding which tool is correct. How evil! 

When you first start, the window given to you to fix the given item is quite lenient. However, with each successful fix, the window gradually gets shorter and shorter, giving you less time to react before a 'Strike' is given. Based on my playtest using my 'average' gaming skills, it will eventually get to a point where you its physically impossible to select the right tool in time. But thats the fun of it! You can challenge your friends to see who can get the highest score, and compete against one another!

Lastly, the game also features multiple levels, specifically 3 levels, each rising in difficulty. To make things more difficult, instead of decreasing the reaction time window, I introduced 'Conveyor Belt Positions'. Essentially, levels 2 and 3 introduce the added feature of selecting the correct 'Position' of which the given item originates from. Meaning, you have to select both the correct tool and the correct position! The hardest level, level 3, introduces 4  conveyor belts positioned as top-right, bottom-right, top-left, bottom-left (refer to Game_Assets)!
